Local Batch Image Utility

Image2 PPT 图片批量生成器

输入 PPT 整体风格和每页提示词，并行调用 GPT image2 或兼容中转站，生成图片包、纯 PDF 和图片版 PPTX。

API Key 不写入磁盘
1

API 配置

支持 OpenAI 官方地址、标准 Images API，以及使用 Chat Completions 出图的兼容中转站。

中转站配置示例：Base URL 填 http://216.234.142.96:3000 或 https://www.dreamfield.top，不要手动加 /v1/images/generations；API Key 填中转站提供的 Key；模型填 gpt-image-2。协议建议选"自动"，如果中转站说明使用 /v1/chat/completions 出图，就选 "Chat Completions"。并发越高速度可能越快，但也更容易触发中转站限流，建议先从 2–5 开始。
2

风格与页面卡片

选择固定风格或自定义整体风格，每张卡片可以输入文本并上传最多 3 张参考图片。生成后每张卡片右侧会显示预览图，支持单独重新生成。

输出语言会统一注入每一页提示词。有参考图片的页面会自动使用 Chat Completions 多模态格式；所有页面仍会按"并发页数"并行生成。每页生成后可单独点击"重新生成"按钮修改。
